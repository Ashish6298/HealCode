HealCode CLI --no-banner Option Validation Report
==================================================

Implementation Summary
----------------------
HealCode CLI Modernization introduces complete positional support for the global `--no-banner` flag. The CLI entrypoint pre-processes the `argv` stream to extract and set the banner suppression, JSON output, and logging override variables independently of command parser constraints. This resolves the limitation where subparsers throw unrecognized argument exceptions for global flags placed after subcommands.

Modified Files
--------------
- `healcode/cli/entrypoint.py` (added pre-processing logic for global arguments)
- `healcode/cli/parser.py` (cleaned up duplicate argparse parameter bindings)
