----------------------
HealCode leverages Python's standard `argparse` module, which automatically manages `-h` and `--help` options for both the main command parser and all registered subcommands. This ensures clean help-page rendering, zero side effects (no scanners executed, no configs loaded or written, no files touched), and a safe exit with status code `0`.
