HealCode Baseline Command Modernization Validation Report

Implementation Summary
----------------------
HealCode CLI Modernization Phase 11 modernizes and hardens the `baseline` command. It introduces checks to gracefully handle duplicate baseline creation attempts, detects and handles corrupted or malformed baseline JSON metadata, and prints compliant, structured JSON responses matching the standard CLI schema whenever `--json` is supplied.

- `healcode/cli/commands/baseline.py` (updated baseline command with duplicate baseline checks, malformed data handlers, and structured JSON output formats)
