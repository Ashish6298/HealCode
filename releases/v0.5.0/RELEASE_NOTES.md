# HealCode v0.5.0 Release Notes

HealCode Phase 5 (v0.5.0) introduces comprehensive Docker and container environment intelligence scanning.

## Features Added
- **Docker Health**: Inspects docker client/server configuration and daemon state.
- **Dockerfile Audit**: Verifies base image latest tags, non-root execution, and missing healthchecks.
- **Docker Compose Scanner**: Validates restart policies and service configurations.
