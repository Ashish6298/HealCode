# HealCode v0.9.0 Release Notes

HealCode Phase 9 (v0.9.0) transforms HealCode into an AI-powered Engineering Intelligence Platform with modular root-cause analysis, correlated issue grouping, prioritized repair recommendations, executive summaries, and privacy-first design. The AI layer is entirely optional and offline-first.

## Highlights

- **AI Intelligence Engine** — Root cause, correlation, recommendation, prioritization, and summary engines.
- **AI Provider Abstraction** — Pluggable interface for Offline, OpenAI, Anthropic, Gemini, Ollama, and OpenAI-compatible endpoints.
- **Privacy Masking** — Automatic secret scrubbing before any data leaves the machine.
- **`healcode ai` Command** — AI-enriched analysis with `--offline` flag.
- **Offline-First** — Full diagnostics functionality without any AI provider configured.
