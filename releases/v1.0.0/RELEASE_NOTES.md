# HealCode v1.0.0 Release Notes

HealCode v1.0.0 (Production Readiness & Developer Experience) is officially released.

## Highlights
- **Profile System**: Target scans using preset profiles (DevOps, Security, Minimal, Full).
- **Baseline & Drift Detection**: Save snapshots and compare against previous states.
- **Watch Mode**: Monitor codebases for real-time diagnostics changes.
- **Plugin Marketplace Command**: Pluggable SDK with command discoverability.
- **Update Notification System**: Keep up-to-date with non-intrusive cached prompts.
- **GitHub & CI/CD Integrations**: Off-the-shelf action workflows.
