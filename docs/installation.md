# Installation Guide

This document describes how to install and setup HealCode on various platforms.

## Prerequisites
- Python 3.11 or higher
- Pip package manager

## Direct Installation

To install HealCode globally or inside a virtual environment:
```bash
pip install healcode
```

## Platform Compatibility
- **Windows**: Fully supported (CMD, PowerShell, Git Bash).
- **Linux**: Fully supported.
- **macOS**: Fully supported.
